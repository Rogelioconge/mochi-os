# Localisation

**Sources:** `patch/i18n.h`, `tools/pod_i18n.py`, `tools/awtk_strings.py`, `tools/mod_strings.py`.
All text M1+ Music adds follows Settings > General > Language. We translate it ourselves into the 13
languages of the language menu, using the stock terms where they exist (library, artist, shuffle).
No hook.

## How the stock app translates

- A widget stores a key (`tr_text`); `widget_set_tr_text` sets the key and the text looked up in
  the current language table. A `.bin` property `tr_text = key` does the same when a page is built.
- The lookup is a binary search by `strcmp` and returns the **key itself** when the table or the
  entry is missing.
- A language change reloads the table and re-translates every open window, ours included. A widget
  set with `widget_set_text_utf8` keeps its text, so composed texts are rebuilt each time they are
  shown.

## Tables

`strings/<lang>_<COUNTRY>.bin` (`tools/awtk_strings.py`) holds key/value pairs sorted by key, UTF-8.
There are 16 tables and the language menu reaches 13: `zh_CN` (the default), `zh_HK`, `en_US`,
`ja_JP`, `ko_KR`, `fr_FR`, `ge_DE`, `sp_ES`, `it_IT`, `th_TH`, `po_PL`, `ru_RU`, `uk_UK`. `de_DE`,
`es_ES` and `pl_PL` are CD ripper stubs nothing loads.

Stock translations are uneven (some untranslated, `msg_no` "Cancel" is "Nein" in German). So a
stock key is used only where it is the same English text and reads well in every language
(`STOCK` in `tools/pod_i18n.py`).

## Stock fixes

`STOCK_FIX` in `tools/pod_i18n.py`, applied by `tools/mod_strings.py`, translates stock texts that
stock left in English in ten tables (Look up Album / Artist, keyboard placeholders, Search's hint,
sort orders, format-card texts, rotation angles, the lamp rows, the digital filters, and similar).
It also fixes single-table errors: English left in place, another language's text, a misspelling,
two missing `it_IT` keys.

- `en_US`, `zh_CN` and `zh_HK` are never touched.
- The build refuses a text the table already has or a text without ink in the font.
- The digital filters keep their English names in Thai.
- Left as they are: brand and format names, time zone names, EQ genre names, and pages this
  firmware does not show.

## Our texts

Every other text we add is a key of our own whose **key is the English text** (`TEXT` in
`tools/pod_i18n.py`, 13 languages; brand names `M1+ Music` and `Tidal` stay plain). A missing table
or entry shows English.

- `tools/mod_strings.py` (a build step) adds the keys to all 16 tables (the three stubs get their
  twin's text). It refuses a table that already has one, a stock key that is gone, or a text without
  ink in the shipped font.
- Assets carry `tr_text = key` (`pod_i18n.text_prop`). The payload uses `TR(key)` from
  `patch/i18n.h` for composed texts and the message box, and `widget_set_tr_text` for a label.
- Composed texts: the Cover Flow progress is `TR("Preparing covers...")` + `" done/total"`. A count
  uses the key `%d track` or `%d tracks` (chosen by `n == 1`) with the number put where the text has
  its `%d`, never a printf format. Polish, Russian and Ukrainian have three plural forms, so they
  word both keys as a label ("Utwory: 12").
- **Adding a text:** a `TEXT` entry with all 13 languages (the test fails otherwise), then its use
  in an asset or the payload. `test/pod/i18n.py` checks widths and glyphs.
- **Widths** are measured in the shipped font for every language: row labels (21 px, 187-212 px;
  137 px on the Main Menu page), page titles (20 px, 178-248 px), message-box lines (20 px, 260 px;
  longer scrolls), the album button (110 px), the count line (15 px, 154 px) and the Cover Flow
  status (20 px, 300 px). A string that does not fit is reworded in that language (for example
  `Cover Flow orizz.` in Italian, `Jetzt läuft` for the German Now Playing).
- Pages that add no text: the pull-down dialog, lock screen and Now Playing. Control Center adds
  only its own title and tile labels.

## Fonts

One font file with no fallback covers every language: [fonts](fonts.md). Our texts already have ink
in it, so the subset needs no extension. `zh_HK` shows the TC forms and `ja_JP` the JP forms.
